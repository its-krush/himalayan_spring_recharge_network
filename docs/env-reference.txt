Environment reference for local and Render deployment

NODE_ENV=development
PORT=3000
# Optional: omit to run without PostgreSQL persistence.
DATABASE_URL=postgresql://app:app_password@localhost:5432/himalayan_spring
# Optional: Render generates this automatically; local fallback is used when omitted.
JWT_SECRET=replace-with-a-long-random-secret
ENABLE_LIVE_INGESTION=false

No Manus OAuth, owner identity, or external account values are required. The app's built-in local demo login creates a DBA/administrator session.
